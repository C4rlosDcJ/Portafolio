## Stack Tecnológico del Portafolio

Este proyecto fue reconstruido desde cero utilizando herramientas modernas del ecosistema frontend:

*   **React 18** - Biblioteca principal de UI.
*   **Vite** - Herramienta de compilación ultrarrápida.
*   **Framer Motion** - Animaciones fluidas, transiciones de scroll y efectos visuales.
*   **React Icons** - Sistema de íconos vectoriales.
*   **React Parallax Tilt** - Efecto 3D interactivo en las tarjetas de proyectos.
*   **Variables CSS Globales** - Sistema robusto de estilos, tema oscuro personalizado (Deep Navy & Cyan).
